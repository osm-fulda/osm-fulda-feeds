👋 **Was hier passiert**

Ein Bot meldet jede Person, die ihr **erstes Changeset überhaupt** im Landkreis Fulda hochlädt. Wer Zeit hat, schickt ihr eine kurze Begrüßung. So finden neue Leute zu uns, statt nach ein paar Wochen allein wieder aufzuhören.

**Was tun?**
1. Auf die Meldung klicken, das Profil öffnet sich auf osm.org.
2. Unter „Changesets“ prüfen: Liegt das erste Changeset im Landkreis? Der Bot sieht auch etwa 11 km darüber hinaus.
3. Kurz ansehen, was die Person gemacht hat.
4. Im Profil „Nachricht senden“ und die Vorlage unten anpassen.
5. ✅ unter die Meldung setzen, damit niemand doppelt schreibt.

**Vorlage** (Betreff und Text kopieren, die Links bleiben so erhalten)
Betreff: `Willkommen bei OpenStreetMap in Fulda! 👋`

```
Hallo {Name},

danke für deine erste Änderung in OpenStreetMap! Wir sind eine kleine Gruppe, die im Landkreis Fulda mappt. Wenn du Fragen hast oder Lust auf mehr bekommst, schau gerne in unseren Chat: [#osm-fulda auf Matrix](https://matrix.to/#/#osm-fulda-space:shivering-isles.com). Tipps für den Anfang stehen auf unserer [Wiki-Seite](https://wiki.openstreetmap.org/wiki/Fulda).

Viele Grüße
{dein Name}
```

**Tipp:** Ein persönlicher Satz zum ersten Changeset wirkt Wunder. Kritik gehört nicht in die erste Nachricht.

Mehr dazu, auch eine englische Vorlage: https://wiki.openstreetmap.org/wiki/Fulda/Neue_Mapper_begrüßen
