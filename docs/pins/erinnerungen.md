⏰ **Erinnerungen**

Du willst dich um eine Meldung später kümmern? Antworte auf die Meldung, dann erinnert dich der Bot zum Termin.

Einmalig, damit der Bot deutsche Datumsangaben versteht:

```
!remind locale de_de
```

Dann auf die Meldung antworten, zum Beispiel:

```
!remind in 2 wochen nachsehen
```

Auch möglich: `!remind samstag um 10:00 …` oder `!remind 01.05.2027 …`. Wer auch erinnert werden will, setzt 👍 unter die Bestätigung des Bots. `!remind list` zeigt deine Erinnerungen. Löschen: die eigene `!remind`-Nachricht entfernen.
