# docs

## pins/

Texte für angepinnte Nachrichten in den Matrix-Räumen.

- `erste-changesets.md`: Pin für `#osm-fulda-erste-changesets:matrix.org`.

So aktualisierst du einen Pin:

1. Kopiere den ganzen Text der Datei in den Element-Composer und sende ihn.
2. Pinne die neue Nachricht an.
3. Löse die alte Nachricht vom Pin.

Vorlagen zum Kopieren stehen in einem Codeblock. Sonst zeigt Element
`[Text](URL)` als Link an, und beim Kopieren fehlt die URL.
